# RuoYi-Vue 后台管理系统 — 软件测试实战项目

> 一份完整的软件测试作品集。基于若依 RuoYi-Vue 前后端分离框架，完成了**登录认证、用户管理、角色管理与数据权限**三大核心模块的测试，覆盖功能测试、接口测试、数据库验证与越权测试。

| 项目 | 内容 |
|------|------|

| 测试类型 | 功能测试 / 接口测试（Postman）/ 数据库验证（SQL）/ 权限与越权测试 |

| 发现缺陷 | 4 个（均一般级） |
| 质量结论 | 通过，可发布 |

## 发现的缺陷

| 编号 | 标题 | 严重程度 |
|------|------|----------|
| BUG_LOGIN_001 | 连续输错密码无防暴力破解限制 | 一般（安全） |
| BUG_USER_001 | 手机号输入 11 位字母仍能保存 | 一般 |
| BUG_USER_002 | 删除用户后 sys_user_role 关联表残留 | 一般 |
| BUG_ROLE_001 | 修改数据权限后在线用户数据范围未即时刷新 | 一般 |

## 面试可讲的核心能力

1. **读源码设计用例**：从 SysUser/SysRole 的校验注解里挖出「手机号无正则」等真实缺陷
2. **边界值测试**：密码 4/5/20/21、手机号 10/11/12 等边界覆盖
3. **数据权限与越权测试**：5 种数据范围（全部/自定义/本部门/本部门及以下/仅本人）横向+纵向越权验证
4. **SQL 数据验证**：逻辑删除、级联清理、关联表脏数据检查
5. **接口测试**：Postman 完整链路（验证码→登录→token→受保护接口）
