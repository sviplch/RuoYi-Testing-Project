# 00 — 项目选择与环境搭建

---

## 一、项目选择

### 方案 A（推荐）：若依 RuoYi-Vue 前后端分离版

**为什么推荐它**：
- 国内企业后台管理系统的事实标准，面试官都认识
- 自带登录、用户管理、角色、菜单、部门、岗位、字典、参数、日志、定时任务等几十个功能模块
- 前后端分离，暴露标准 REST API，正好用 Postman/JMeter 练接口测试
- 后端 Spring Boot + MySQL + Redis，能练 SQL 数据验证

**技术栈**：
- 前端：Vue 2 + Element UI
- 后端：Spring Boot 2 + MyBatis + MySQL + Redis
- 接口认证：JWT Token

**默认账号**：admin / admin123

---

### 方案 B（轻量）：若依 RuoYi 单体版

- 不需要 Redis、不需要 Node.js 前端
- 只要 Java + MySQL 就能跑
- 缺点：服务端渲染（Thymeleaf），接口测试机会少，不适合练 Postman

---

### 方案 C（最简单）：自己写个极简项目

如果你环境搭建实在有困难，可以退而求其次：
- 用 Spring Boot 写一个"学生管理系统"，只有登录 + 学生信息增删改查
- 优点：代码都是你写的，每个功能都了如指掌，面试时能讲透
- 缺点：功能少，测的内容有限

**我的建议**：优先方案 A。哪怕搭建要花一两天，这个投入对面试的回报是最大的。

## 二、环境准备（Windows）

### 2.1 需要安装的软件

| 软件 | 用途 | 下载地址 | 版本建议 |
|------|------|----------|----------|
| **JDK** | 跑后端 | 官网或镜像 | JDK 8 或 11 |
| **MySQL** | 数据库 | 官网 | 5.7 或 8.0 |
| **Redis** | 缓存 | GitHub（Windows 版） | 5.x |
| **Maven** | 后端构建 | 官网 | 3.8+ |
| **Node.js** | 前端 | 官网 | 16+ |
| **IntelliJ IDEA** | 后端开发工具 | 官网 | 社区版即可 |
| **VS Code** | 前端/看代码 | 官网 | 最新 |

> 如果嫌一个个装麻烦，可以搜"若依 RuoYi-Vue 本地部署教程"，网上有大量图文/视频教程，照着做即可。这里给关键步骤。

---

### 2.2 拉取项目

```bash
# 后端
git clone https://gitee.com/y_project/RuoYi-Vue.git

# 前端（RuoYi-Vue 自带 ui 目录，也可以单独拉 ruoyi-ui）
# 直接用 RuoYi-Vue 仓库里的 ruoyi-ui 目录即可
```

如果不用 git，直接去 gitee 下载 zip 压缩包解压也可以。

---

### 2.3 建数据库

1. 用 Navicat 或 MySQL 命令行创建一个数据库：
```sql
CREATE DATABASE ry_vue DEFAULT CHARACTER SET utf8mb4;
```

2. 导入项目里自带的 SQL 脚本：
- 路径：`RuoYi-Vue/sql/ry_2021xxxx.sql`（日期可能不同）
- 和 `sql/quartz.sql`（定时任务表）

导入后数据库里会有 `sys_user`、`sys_role`、`sys_menu` 等表。

---

### 2.4 配置并启动后端

1. 用 IDEA 打开 RuoYi-Vue 根目录（后端）
2. 修改配置文件 `ruoyi-admin/src/main/resources/application-druid.yml`：
```yaml
url: jdbc:mysql://localhost:3306/ry_vue?useUnicode=true&characterEncoding=utf8
username: root
password: 你的MySQL密码
```

3. 确认 Redis 已启动（双击 redis-server.exe），端口默认 6379

4. 启动后端：
- 找到 `ruoyi-admin` 模块下的 `RuoYiApplication.java`，右键运行
- 看到 "启动成功" 字样，后端就跑起来了，默认端口 **8080**

---

### 2.5 启动前端

```bash
cd ruoyi-ui
npm install        # 第一次装依赖，可能要几分钟
npm run dev        # 启动前端，默认端口 80
```

浏览器打开 `http://localhost`，看到登录页就成功了。

---

### 2.6 验证环境 OK

1. 浏览器登录 `admin / admin123`，能进入后台首页 → 前端通了
2. 打开 `http://localhost:8080/captchaImage` → 返回验证码 JSON → 后端通了
3. 用 Postman 调登录接口（见实战示例）→ 接口测试环境就绪

## 三、你练习的重点模块

RuoYi 有几十个模块，你不用全测。**重点测这两个就够形成完整的测试经历了**：

| 模块 | 为什么选它 | 能练到什么 |
|------|-----------|-----------|
| **登录模块** | 所有系统都有，边界和异常多 | 等价类、边界值、安全测试、接口测试 |
| **用户管理模块** | 标准 CRUD，涉及数据库 | 增删改查用例、SQL 数据验证、分页查询 |

测完这两个模块，你就完整走过了"需求分析 → 计划 → 用例 → 执行 → Bug → 报告"的完整流程，面试有得聊。

---

## 四、开始前的心理准备

- 你不是来学 Spring Boot 开发的，**代码不用全看懂**，重点是用测试的眼光去看功能
- 遇到不懂的代码没关系，你的任务是：**这个功能用户怎么用？怎么用会出错？怎么验证数据对？**
- 全程做好记录——测试用例、Bug 单、测试报告，这些是你面试时能拿出来的"证据"
